# webchat

Phòng chat web realtime (Socket.io). Vào phòng cần nhập tên; gửi link public cho mọi người (Zalo, Messenger…).

## Chạy local

```bash
npm install
npm start
```

Mở http://localhost:3000

## Deploy (Render)

Kết nối repo GitHub → dùng `render.yaml` hoặc Web Service: build `npm install`, start `npm start`.
